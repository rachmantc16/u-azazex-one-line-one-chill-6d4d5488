A tiny deterministic Node program for make.fun's "One Line, One Chill" bounty. Running it writes a single horror sentence (166 characters, one line, no trailing newline) to `/output/entry.txt`: at 7:42, a six-year-old's voice memo from the school bus whispers that the driver is wearing his father's face — and behind him, close and clear, the father hears his own laugh. An AI horror-editor judge compares the line head-to-head against other entries on how frightening, vivid, original, and well-crafted it is.

## Run it

```sh
node main.ts
```
